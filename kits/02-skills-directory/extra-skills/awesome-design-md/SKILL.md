# awesome-design-md

A local copy of github.com/VoltAgent/awesome-design-md at `~/Documents/awesome-design-md`.
Each brand is `design-md/<brand>/DESIGN.md` (colours, type, spacing, components, tone).

## Use

1. If `~/Documents/awesome-design-md` is missing, clone it:
   `git clone --depth 1 https://github.com/VoltAgent/awesome-design-md.git ~/Documents/awesome-design-md`
2. List brands with `ls ~/Documents/awesome-design-md/design-md`; pick the one the owner
   named, or suggest 2 or 3 that fit their business.
3. Read that DESIGN.md fully, then copy it into the project as `DESIGN.md` so later edits
   keep following it.
4. Build to those rules. It's a style reference only: never copy the brand's logo, name,
   or trademarked assets into the owner's work.

## Update

`git -C ~/Documents/awesome-design-md pull --ff-only`
