# Kit 04: AI Workforce

**Day 1, blocks 10 and 11 (Exercise 2).** The AI Chief suggests the first AI employees,
the owner picks, Claude builds them, and each one does a real task on its first shift.

## Before this kit

Kit 03 is done: `02 AI Team/org-plan.md` exists and the AI Chief is hired in Grok Bot.

## The one prompt (owners paste this into Claude)

```
Run Kit 04 from my Documents/work-without-working-kit folder. Read kits/04-ai-workforce/SETUP.md and follow it step by step with me.
```

## What happens

1. Claude gives the owner a prompt to paste into Grok: "Which 1 or 2 AI employees should I hire first?"
2. The owner pastes Grok's job descriptions back into Claude and picks who to hire
3. Claude builds each AI employee as a skill in the business folder
4. First shift: each employee does one real task
5. The owner marks each result Pass or Fix on a scorecard
6. Claude fixes the employee once if needed

Grok and Claude aren't connected yet in this kit, so the owner copies between them.
Kit 05 connects them.

## They leave with

- [ ] 1 or 2 AI employees at `.claude/skills/<role>/SKILL.md`
- [ ] A job description for each in `02 AI Team/`
- [ ] At least one real task done and scored Pass in `02 AI Team/scorecard.md`

## Takes about

60 to 80 minutes.
