# Kit 02: Build Your Own Tool

**Day 1, block 6 (Exercise 1).** The owner builds one skill, a reusable tool that does one
repetitive task from their bottleneck, without writing code.

## Before this kit

Kit 01 is done, and they've run Grill Me, so `00 Bottleneck/bottleneck-brief.md` exists.
They're in a Code session with their business folder (`WORK FOLDER/<Business>`) selected.

## The one prompt (owners paste this)

```
Run Kit 02 from https://github.com/ecommercefastlaunch-debug/work-without-working-kit. Read kits/02-build-your-tool/SETUP.md (it's also in my Documents/work-without-working-kit folder) and follow it step by step with me.
```

## What Claude does with them

1. Reads their CLAUDE.md and bottleneck brief
2. Suggests 3 repetitive tasks; the owner picks one
3. Asks for one real example: what goes in, and what good looks like
4. Writes the skill in their business folder
5. Runs it on the real example and saves the result
6. Improves it once if the owner wants changes
7. Gives a done checklist

## They leave with

- [ ] One skill at `WORK FOLDER/<Business>/.claude/skills/<skill-name>/SKILL.md`
- [ ] One real output from it in `03 Outputs`
- [ ] The skill listed in `02 AI Team/my-tools.md`
- [ ] Knowing how to run it again: type `/<skill-name>` in a session in their business folder

## Takes about

30 minutes. Keep it to one task. Good first tools: reply drafts for common customer
questions, a quote or price computation, captions for a product, a daily sales summary
from a pasted list, a follow-up message for unpaid orders.

**Helpers:** steer owners away from tasks that need logging in to another app (Facebook,
Shopee, bank). Those come later. Today's tool works on text and files on the laptop.
