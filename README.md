# Work Without Working: Setup

One kit for now: **Kit 01 Setup**. It's a folder Claude follows, so the owner pastes one line
and Claude does the setup with them.

**Repo link:** `https://github.com/ecommercefastlaunch-debug/work-without-working-kit`

**Day 1 workbook (6 pages, print A4):** [PDF](handout/work-without-working-workbook.pdf). The setup, plus worksheets.

| Kit | What the owner leaves with | Runs on |
|---|---|---|
| [01 Setup](kits/01-setup/) | One prompt installs everything: Homebrew (Mac), Git and GitHub, FFmpeg, Node.js, the kit files, the WORK FOLDER with a CLAUDE.md, and 12 Claude skills | Mac, Windows |

After Kit 01, owners open their Code sessions in the WORK FOLDER. Every new project gets its own folder
there, and everything Claude makes goes in that project's `Outputs` folder.

## How an owner uses it

In the Claude desktop app, open the **Code** tab and paste the one-line prompt
from the Kit 01 README (or page 4 of the workbook). Claude reads the kit's `SETUP.md` and walks them through it.

## Rules the kit follows

- Claude explains what it's doing in plain words and checks it worked.
- Claude asks before installing anything (in Kit 01, pasting the prompt is the yes for the whole list).
- Passwords, payments and account sign-ups are always done by the owner, never by Claude.
- Skills from other people are installed from their original GitHub repo, with credit.
