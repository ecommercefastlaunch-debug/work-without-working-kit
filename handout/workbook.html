01

Work Without Working Setup Kit

Do this first · One prompt installs everything · About 15 to 25 minutes

Paste one prompt. Claude installs everything below for you. You only approve when your computer asks.

Set me up with Kit 01 from https://github.com/ecommercefastlaunch-debug/work-without-working-kit. Read kits/01-setup/SETUP.md and install everything for me. I'll allow what's needed.

What's included

Homebrew

Mac only. The Mac's installer for everything below.

Git + GitHub app

Downloads files and skills from GitHub.

FFmpeg

Lets Claude cut and convert your videos.

Node.js

Runs tools like video editors and app builders.

GitHub account

No account yet? Claude opens the sign-up page. You sign up and sign in yourself.

WORK FOLDER

Your home base, with a file that tells Claude about your business.

What you do

  • Mac: a Terminal window opens. Click OK, type your Mac password (nothing shows while you type), press Return.
  • Windows: say yes to the programs' terms, and click Yes when Windows asks to allow changes.
  • Answer one question: what you sell and who buys it, in one or two sentences.
  • GitHub: sign up or sign in yourself, then paste the code Claude shows and click Authorize.
  • At the end Claude shows a ✓ for each item. Tick the boxes above.

Your WORK FOLDER

WORK FOLDER/
  CLAUDE.md      your business + the rules
  <project>/    one per project
    Outputs/    all Claude makes

From now on

  • Start a new Code session and choose your WORK FOLDER.
  • Say what you're working on. Claude makes a folder for it.
  • Everything it makes goes in that project's Outputs.
